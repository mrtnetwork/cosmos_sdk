# Dart Cosmos SDK

Dart library for Cosmos SDK and Cosmos EVM networks: build, sign, encode, decode, and broadcast transactions over RPC, REST, or gRPC — with pre-generated protobuf models for 15+ chains and a generator for any other chain's protos.

This package is the continuation of the original
[mrtnetwork/cosmos_sdk](https://github.com/mrtnetwork/cosmos_sdk).

## Crypto engine: `blockchain_utils` dual backend

Key cryptography (secp256k1, ETH-secp256k1, secp256r1, Ed25519) lives in
[`blockchain_utils`](https://github.com/mrtnetwork/blockchain_utils): pure
Dart by default, optional Rust backend (FFI on native, WASM on web). When set
(`blockchainUtils.setRustApi()`), all high-level crypto used here routes
through Rust. Rust core:
[mrtnetwork/blockchain-utils](https://github.com/mrtnetwork/blockchain-utils).

## Breaking changes

- **v4.0.0 — protobuf models moved to `onchain_proto`.** All protobuf messages are generated by the [onchain_proto](https://github.com/mrtnetwork/onchain_proto) package; class names, file locations, and import paths changed. Update imports when upgrading to v4.
- **All legacy exception classes removed — every error is `BuError`.** Failures throw `BuError` with a `CosmosErrorType` taxonomy value (`domain: 'cosmos'`: plugin, Amino JSON parser, THORNode). Update `catch` clauses and `on` filters to `BuError`.

## Features

### Transactions & keys

| Area | Support |
|---|---|
| Signing | Direct (Protobuf), Amino, multisig |
| Keys | secp256k1, ETH-secp256k1 (EVM chains), secp256r1, Ed25519 |
| Builder | Fee, memo, timeout, tip, multi-message batching |

### Encoding

| Area | Support |
|---|---|
| Formats | Protobuf binary, JSON, Amino JSON, binary |
| Registry | Dynamic `typeUrl`-based decoding (`CosmosMessageRegistry`) |
| Generator | `dart run proto/builder.dart` — models for any chain's `.proto` files |

### Providers

| API | Support |
|---|---|
| RPC / REST / gRPC | Full node clients, broadcast, simulate |
| THORNode | Midgard / THORNode models (fixed parsing) |
| Chains | Cosmos Hub, Osmosis, THORChain, Injective, Evmos, Osmosis, Stride, Secret, … |

### Protobuf packages

Pre-generated models for `cosmos.*`, `ibc.*`, `tendermint.*`, `cosmwasm.*`,
`ethermint.*`, `evmos.*`, `injective.*`, `osmosis.*`, `secret.*`,
`stratos.*`, `stride.*`, `thorchain.*`, `chain4energy.*`, `circle.*`,
`initia.*`, `opinit.*`.

> The full generated set exceeds 20 MB — import only the packages you use.
> `CosmosMessageRegistry` retains every registered type (binary-size cost);
> decode concrete types directly when dynamic decoding isn't needed.

exercise both the pure-Dart and Rust/WASM backends.
